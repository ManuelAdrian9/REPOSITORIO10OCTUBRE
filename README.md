# Práctica: Métodos Iterativos (Jacobi y Gauss-Seidel)

Este proyecto resuelve un sistema de ecuaciones lineales de 3x3 utilizando programación modular en Java.

## Requisitos
* Java JDK 8 o superior instalado.

## Compilación y Ejecución
1. Abre tu terminal en la carpeta raíz del proyecto (src).
2. Compila las clases:
   SISTEMAECUACIONES
   METODOSITERATIVOS
   
4. Ejecuta el programa principal:
   MAIN
